## 🧭 About me

A systems analyst: I turn vague stakeholder wishes into clear requirements, diagrams and task specifications that a development team can actually work with.

- 🎓 Studying Software Engineering at the **Higher IT School (HITs), Tomsk State University**
- 🧩 Working across the full analysis cycle: requirements gathering → modeling → documentation → sign-off
- 📐 Designing processes and data: **BPMN**, **UML**, **ER models**
- 🔌 Comfortable with integrations: **REST API**, **SOAP**, data exchange formats
- 🗄️ Writing **SQL** and designing database structures
- 🧠 Learning application architecture and development methodologies (Agile, Scrum, Kanban, Waterfall)
- 💬 I like polishing documentation until it reads clearly the first time
